## 先跑这三步，不对就停

**这条不过，后面每条都无从谈起。**

| # | 操作 | 通过判据 |
|---|---|---|
| 0.1 | 打开 App | 状态栏不是「初始化失败」 |
| 0.2 | 点【**开始工作**】 | **画面出现**（不是黑屏/白屏） |
| 0.3 | 看画面中间 | **有一个框**：框外偏暗，框上有绿色四角 |

**同时**：状态栏写「**把面单放进取景框**」，**不是**「录制中」。

> 黑屏 → 预览没挂上会话
> 没有框 → 覆盖层没画出来
> 已经是「录制中」→ 退回"点按钮就开录"了

## 1.1 连续录 30 分钟不断

| | |
|---|---|
| **前置** | 模式：连续扫 · 静止档位：**关闭** |
| **操作** | 开始工作 → 扫一张面单开录 → 手机架着录 30 分钟 |
| **判据 1** | 「已录」一直往上走，**中途没自己停** |
| **判据 2** | 结束时点【结束工作】→ 状态变「已收尾 · 索引里共 N 条」 |
| **判据 3** | **N > 1** —— 说明分段轮转发生了 |

> 判据 3 很关键：30 分钟只出 1 条，说明轮转没发生或丢段了。

---

## 1.2 杀掉 App → 重启后收尾孤儿

| | |
|---|---|
| **前置** | 随便什么模式 · 静止档位：**关闭** · 时长兜底：**关闭** |
| **操作** | 开始工作 → 扫面单开录 → **录满 2 分钟以上** → **上滑杀掉 App** → 重新打开 |
| **判据 1** | 出现橙色的「**启动时收尾的孤儿分段**」卡片 |
| **判据 2** | 卡片写「已收尾 · N 段 · **进程被杀**」 |
| **判据 3** | 顶部诊断的**索引条数比杀之前多** |

> **必须录满 2 分钟。** 分段是 1 分钟一段，不跨过边界就没有可收尾的东西。
> 杀掉之前先看一眼顶部「工作区 N 个会话（未收尾 M）」，把这个数记住。

| | |
|---|---|
| **前置** | 模式：连续扫 · 静止档位：**2 分钟** · 时长兜底：**关闭** |
| **操作** | 开始工作 → 扫面单开录 → **把手机架着完全不动** |
| **判据** | 2 分钟后**自动停止**，事件里出现「停录 · **画面静止**」 |

## 1.4 ★ 静止封顶修正

**这是最容易写错的一条。**

| | |
|---|---|
| **前置** | 模式：连续扫 · 静止档位：**2 分钟** |
| **操作** | **先别碰手机，让它静止放着 10 分钟以上** → 然后开始工作 → 扫面单开录 |
| **判据** | **不得立刻停止**；要等满 2 分钟才停 |

> 不加封顶的话，一开录就会看到「画面已经静止了 10 分钟」而当场停掉。

---

## 1.5 错码保护

| | |
|---|---|
| **前置** | 模式：**同码停** · 静止档位：关闭 · 时长兜底：关闭 |
| **操作 A** | 开始工作 → 扫面单 **A** 开录（扫完把 A 拿开）→ 扫面单 **B** |
| **判据 A** | **不停止** 且 事件里出现「🔊 **面单不同**」 |
| **操作 B** | 再扫回 **A** |
| **判据 B** | **停止**，事件里出现「停录 · **同码复扫**」 |

> 没有两张不同面单时：用界面上的「**当作扫到了这个单号**」按钮，
> 改单号文本框的内容再点，效果一样。

---

## 1.6 时长兜底

| | |
|---|---|
| **前置** | 模式：连续扫 · 静止档位：**关闭** · **打开「时长兜底加速」开关** |
| **操作 A** | 开始工作 → 扫面单开录 → **什么都不做** |
| **判据 A** | 约 **20 秒**后出现提示与【停止】【继续】两个按钮；**不操作**约 **10 秒**后自动停止，事件里出现「停录 · **时长兜底**」 |
| **操作 B** | 重新开始 → 等到询问出现 → 点【**继续**】 |
| **判据 B** | **不停止**；约 **30 秒**后**再次询问** |

> 验完可以关掉加速再跑一次真实的（4 分钟问、不操作 5 分钟停）。
> 另外把时长兜底档位改成 **6**，确认是 **6 分钟**才问、不是 4 分钟。

## 1.7 摄像头识码

| | |
|---|---|
| **前置** | 开始工作（不用先开录） |
| **操作 A** | 把有单号的面单放进**框内** |
| **判据 A** | 事件出现「📷 扫到 <单号>」 |
| **操作 B** | 把面单挪到**画面边角**（框外） |
| **判据 B** | **不识别** |
| **操作 C** | 面单**一直摆在框里**不动 10 秒 |
| **判据 C** | **只播报一次**，不会反复刷 |
| **操作 D** | 把面单**拿开 3 秒**再放回框里 |
| **判据 D** | **再播报一次**（这才算"复扫"） |

> **完全识不到码** → 大概率是 `Vision` 的 `orientation`，这是我最没底的一处（本机是 Windows，验不了）。把结果告诉我，我改成 `.right` 或 `.left` 再打一版。
